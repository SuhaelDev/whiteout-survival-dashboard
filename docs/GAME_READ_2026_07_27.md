## Why the dashboard was showing the wrong numbers

Two separate problems, both now fixed.

**1. A stale saved state was winning.** The bundled game read was being skipped whenever
your cloud row had been saved more recently than the read — which it always had, because
the dashboard autosaves as you use it. So the Resources page kept serving numbers captured
on 10 July. Each read now carries a `capture_id`, and a saved state records the last id it
absorbed, so a fresh read lands exactly once per account with no clock comparisons to get
wrong.

**2. The read itself had layers.** `extracted_current.resources` held several generations of
counts under different key names — `pet_wild_marks` alongside `common_wild_marks`,
`strengthening_serum` alongside `pet_serum`, a July-15 speedup breakdown that overrode the
newer totals. The duplicates are deleted; one name per thing now.

# Charm costs: a level is not one tap

The Charms page was quoting a quarter of the real cost. The cause was a reading
mistake, not a maths one.

**A charm level takes several upgrade taps, and the in-game panel only ever quotes the
next tap.** Four taps up to level 11, five from level 12 up. An earlier pass read the
panel figures — 105/105 for level 10, 140/105 for level 11 — and wrote them into the
full-level fields. Its own note recorded what it had done ("per-charm step cost read from
upgrade panel"), and that note was then trusted as a level cost.

The correct figures were never lost: the workbook aggregates sat untouched in the
`workbook_*` fields the whole time. Restoring them and checking against the observed taps
lines up on all three levels that could be checked:

| Level | Taps | Panel quotes | × taps | Workbook | |
|---|---|---|---|---|---|
| 10 | 4 | 105 / 105 / 0 | 420 / 420 / 0 | 420 / 420 / 0 | agree |
| 11 | 4 | 140 / 105 / 0 | 560 / 420 / 0 | 560 / 420 / 0 | agree |
| 12 | 5 | 116 / 90 / 3 | 580 / 450 / 15 | 580 / 450 / 15 | agree |

Level 12 is what proved the five-tap rule — four taps gave 464/360/12 against a workbook
580/450/15, and the gap closed exactly at five. Every level from 3 upward now divides
evenly by its own tap count, which is a decent smell test on the rest of the table.
